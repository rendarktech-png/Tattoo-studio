# ЛИСА — тату-студия

Одностраничный сайт на React, TypeScript и Vite.

## Запуск

```bash
npm ci
npm run dev
```

## Сборка

```bash
npm run build
npm run preview
```

Готовые файлы находятся в `dist/`. Контактные данные и тексты страницы находятся в `src/App.tsx`, стили — в `src/styles.css`, изображения — в `public/`.
