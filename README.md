# ЛИСА — тату-студия

Одностраничный сайт студии в Новосибирске. Проект сделан на React, TypeScript и Vite. Фотографии подставляются из локальных папок; пока файлов нет, интерфейс показывает подписанные заглушки.

## Запуск

```bash
npm install
npm run dev
```

Откройте локальный адрес, который покажет Vite.

Проверка сборки:

```bash
npm run build
npm run preview
```

## Как добавить фотографии

Подготовьте файлы по списку в [ASSETS_REQUIRED.md](./ASSETS_REQUIRED.md) и положите их в указанные папки внутри `public/images/`. Названия файлов должны совпадать точно. В локальном режиме изображения появятся после обновления страницы — менять код не требуется. Опубликованный сайт нужно собрать и развернуть повторно, чтобы новые файлы попали на сервер.

Для фотографий подойдёт WebP в цветовой модели sRGB. По возможности сохраняйте важные части татуировки ближе к центру: превью обрезается по рамке, а полноэкранная галерея показывает снимок целиком.

Логотип находится в `public/logo-lisa.png`. Это исходный файл 240 × 240 пикселей из задания. Для более чёткого отображения на плотных экранах и в соцсетях понадобится оригинал большего разрешения или векторная версия той же композиции.

Тексты и контакты собраны в `src/App.tsx`, визуальная система — в `src/styles.css`.
